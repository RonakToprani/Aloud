# Code of conduct

Aloud is a small project made by readers, for readers. Be kind, be patient,
assume good faith, and remember there is a person on the other side of every
issue and review.

Harassment, personal attacks, and discrimination of any kind are not welcome
here. If something happens that makes you uncomfortable, email the maintainer
at the address on the GitHub profile and it will be dealt with privately.

This is a condensed form of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full.
